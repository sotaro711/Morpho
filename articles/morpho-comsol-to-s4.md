## TL;DR

- 構造色の共同研究で、COMSOL のシミュレーションが 1 条件【◯分】かかり、条件を振れなかった
- 周期構造に特化した RCWA ソルバー **S4** に乗り換え、ブラウザで構造を組んで「計算する」を押すだけのアプリ **Morpho** を作った

## 背景: 構造色の共同研究と COMSOL

【研究の概要。モルフォ蝶のような構造色を、多層膜 + 段差構造で人工的に作る】

対象は次のような構造です。

- TiO₂ / SiO₂ の 7 ペア多層膜（λ₀ = 470 nm の 1/4 波長設計）
- 基板の一部を λ₀/2 = 235 nm だけ持ち上げ、隣のブロックとの位相差で回折を広角化する
- 幅 900 / 600 / 300 nm のブロックが周期 3 µm で並ぶ

見たいのは、波長ごとの回折角度分布、入射角 0/30/60° の反射スペクトル、そして各角度から見たときの色です。

これまで COMSOL（FEM）で計算していましたが、

- 1 条件【◯分】、角度・波長を振ると【◯時間】
- 【ライセンスが研究室の特定 PC にしかない】
- 結果が出るまで次の打ち合わせを待つことになり、議論のサイクルが【週単位】

という状態でした。

## なぜ S4（RCWA）か

[S4](https://web.stanford.edu/group/fan/S4/) は Stanford の Fan 研による RCWA（厳密結合波解析）ソルバーです。

FEM が空間全体をメッシュで切るのに対し、RCWA は「面内に周期的で、厚さ方向に層状」な構造を、層ごとのフーリエ展開で解きます。今回の構造はまさにこの形なので、

- メッシュ不要で、計算量は層数と回折次数でほぼ決まる
- 回折次数ごとの反射率と出射角がそのまま得られる（角度分布が欲しい用途にぴったり）

という利点があります。

## 作ったもの: Morpho

ブラウザで

1. 計算条件（波長範囲・偏光）を入れる
2. 多層膜を積む（ペアをまとめて挿入できる）
3. 段差ブロックを並べる（クリックで「上げ / 平」を切り替え）
4. 「計算する」

だけで、入射角ごとの見た目の色・角度スイープ・反射スペクトルが出ます。構造の断面図は入力に合わせて常時描画され、「見たままが計算される」ことを重視しました。

### アーキテクチャ

![アーキテクチャ](【docs/architecture.drawio.svg を画像で】)

- フロント: Next.js 15 + Plotly
- バックエンド: FastAPI + S4（Python バインディング）。ドメイン / ユースケース / インフラに分け、S4 はソルバーポートの裏に閉じ込めた
- 認証・材料 DB: Supabase
- デプロイ: Cloud Run（S4 は C++ 拡張なので Vercel 等のサーバーレスには載らず、コンテナにした）

## 正しさをどう担保したか

速くても結果が違えば意味がないので、ここに一番時間をかけました。

### アプリと独立した検証スクリプト

アプリのコードを一切 import せず、S4 を直接叩いて研究スライドの構造を再現するスクリプトを先に書きました。COMSOL の結果と

- 回折角度分布のピーク位置
- 470 nm での広角への分配
- 480 nm 付近のスペクトルの山

が定性的に一致することを確認してから、アプリ側に組み込んでいます。

【COMSOL と S4 の比較図を並べる】

### 回折次数の収束と速度のトレードオフ

RCWA は計算に含める回折次数 M（基底数 2M+1）で精度と速度が決まり、計算量は基底数のほぼ 3 乗です。

- M = 30 を基準に、M = 11 で全点の差が 0.03 以下
- 計算は約 **18 倍** 速い

ので既定値を M = 11 にし、収束が怪しい構造のときだけ UI で上げられるようにしました。

### Rayleigh 点の NaN

周期 3000 nm だと λ = 500, 750 nm（周期の整数分の一）で回折波がちょうど面内方向を向き、S4 が NaN や R > 1 を返しました。

- 無損失誘電体に微小吸収 k = 1e-4 を足して縮退をほどく
- `PolarizationDecomposition` を有効にする（金属基板入りの格子で収束が改善）
- それでも NaN の波長は ±0.11 nm ずらして再計算

をソルバーアダプタ内に閉じ込め、API の外には常にきれいなスペクトルだけを返すようにしています。

## 学び

- **問題に合ったソルバーを選ぶのが一番効く**。汎用 FEM から構造特化の RCWA に変えただけで桁が変わった
- **物理の答え合わせはアプリと切り離して先にやる**。検証スクリプトがそのまま回帰の基準になった
- **研究者が触れる形にする**。速いスクリプトがあっても、ブラウザで誰でも回せることで初めて議論のサイクルが変わる
