# 計画: 段付き周期構造(面内周期構造)のシミュレーション対応

作成: 2026-08-26

## ゴール

研究スライド(研究成果0825.pptx)の「段付き周期構造」を Morpho で計算できるようにする。
最終形は GUI で構造を設定 → 角度分布・スペクトル・色が表示される状態。

## 対象構造(スライドより)

- 各ブロック = TiO₂(n=2.3, 51nm)/ SiO₂(n=1.45, 81nm)の 7 ペア多層膜(λ₀=470nm の 1/4 波長設計)
- 基板 = SUS(ステンレス)
- ブロック幅: 900 / 600 / 300 nm の組み合わせ。単位胞 ≈ 3μm で横方向に周期的
- 一部ブロックを「基板上げ」235nm(= λ₀/2)で持ち上げ、隣接ブロックとの位相差で回折を広角化
- 比較対象: 単純多層膜(7.5 ペア、段なし)
- 評価量: ①波長別(400/470/540/600/700nm)の回折角度分布(±80°)、②入射角 0/30/60° の反射スペクトル(380-780nm)、③各観察角の色

## 設計方針

- 検証スクリプトは `backend/scripts/`(export_openapi.py の前例に従う)。`s4web` を import せず S4 を直接叩く。
  物理の正解をアプリと独立に確定させ、以降の回帰テスト基準として残す
- domain の `Region`(層内の矩形領域)は空なら従来の一様層。デフォルト値で完全後方互換
- NaN 対処(Rayleigh 点 / Wood アノマリー由来)は infrastructure 層(S4Solver)に閉じ込める:
  ①NaN 検出時に波長を微小シフトして再計算、②無損失材料への微小吸収付与、③θ=0° 回避。
  ポート越しには常にきれいなスペクトルのみ返す
- CI に S4 はない。物理検証はローカル(PR 1 スクリプト)、CI は fake solver のテストで担保
